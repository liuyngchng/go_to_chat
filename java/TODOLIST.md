## 🚀 建议的认领路径

### 快速看到效果（前端向）
```
faq-kb → llm-dialog → admin-console
```

### 搞 AI 能力（算法向）
```
vector-kb → llm-dialog → mcp-gateway
```

### 搞编排 & 自动化（架构向）
```
agent-factory → agent-orchestrator → mcp-gateway
```

### 全栈通关（从消息进到管理出）
```
faq-kb → llm-dialog → mcp-gateway → handoff → admin-console
```

## 📝 约定

1. 不限制语言、实现方式
1. 每个服务默认监听 `:8080`（部署时通过环境变量 `PORT` 覆盖）
2. 每个服务提供 `GET /health` 健康检查接口，返回 `{"status":"ok"}`
3. 每个服务仓库根目录放一个 `README.md` 说明：接口列表、如何启动、依赖什么
4. 服务间通过 HTTP 通信，不共享数据库
5. 认领后在状态栏写 `🚧 某某某`，完成后改为 `✅ 某某某`
